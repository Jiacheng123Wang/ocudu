P0 的作用是在**写任何模型代码之前**给出这个假设的答案，或者至少给出它的**上界**。

★ 而且 P0 的最大部分**不需要新采集**（主规划 §9.2 的 P0 批：现有存量即可）。

### 1. P0-a：经典链的**导频密度扫描**

- 做法：离线重放，**人为抽取（decimate）DM-RS 符号**（3 → 2 → 1 → 0 符号/槽）；
- 在**同一批采集**上测经典链的 SER / BLER / CRC；
- ★ 产出：**经典链开始显著退化的密度**。
- ★ 判据：若经典链在 1/3 导频时仍接近无损 ⇒ **论文的收益区与我们的工作点无关**。

**待定**：抽取方式（删符号/删子载波/改 comb）、如何保证抽取后仍是合法配置。

### 2. P0-b：经典链的 **SNR 扫描**

- 做法：对同一批采集**加人工噪声**到 0–30 dB；
- ★ 产出：经典链的**拐点 SNR**；
- ★ 与 `memo_04` §2 实测的 SNR 分布对照。

**待定**：加噪方式（在网格上加复高斯 vs 在时域加）、噪声方差标度与 LLR `range_limit` 的关系。

### 3. ★★ P0-c：**上界估计（genie）——最便宜也最关键**

不训练任何模型，直接算"**检测环节可改善的全部空间**"：

| 臂 | 内容 |
|---|---|
| 经典链 | 现行 CE + 均衡 + 解映射 |
| genie 信道 | 用**真实信道**替换估计 |
| genie 符号 | 用**真实发送符号**替换检测 |
| ★ genie 上界 | 逐 RE 的 ML 检测 |

★ 判据：**差值就是"检测环节"可改善的上界**。
若差值已经很小 ⇒ 精度收益的上界就很小 ⇒ **工作流价值必须改由时延论证**。

**待定**：
- genie 信道**从哪来**（T0 仿真可给真值；T1 OTA 没有真值 ⇒ 可能只能用 T0）；
- ★ 若 P0-c **只能在 T0 上做**，它作为"值不值得做"的裁决力有多强？（需要在本文里讨论并写明局限）

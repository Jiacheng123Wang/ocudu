## 1. 目标与边界

★ 把 depth3 的图**向下延伸一段深度** ✓：★ 输入仍是 depth3 的同一张平面 ✓，
★ 模型内完成 **主干 → 码字装配 → N 层消息传递 → 硬判 → 解扰 → TB 比特** ✓。

| 项 | 规定 |
|---|---|
| 模型输出 | **`soft`（训练/评估）** ＋ **`tb_bits`（部署）**（★ 同一图的两种输出 ✓）|
| **CRC** | **不在模型内** ✓（host 在 FAPI 边界做 ✓；那里本来就要回到 CPU ✓）|
| 中间接口 | **没有"给经典解码器的 LLR"** ✓；保留的只有 **RE→码比特的索引映射**（PHY 确定性事实）|

★★ **权威图形状见 §3** ✓；★ 输出边界的由来见过程日志 D18 ✓。

## 3. 图的权威形状

```
输入：平面(612×14×(12+4)) ＋ 常量（Qm/层数/scaling/RNTI/n_ID/rv/TBS/分配）
  └─ depth3 主干（CE/EQ/DEMOD）                      [模型内]
       └─ 码字装配（解速率匹配/解交织，静态置换，零参数）  [模型内]
            └─ N 层 QC-LDPC 消息传递（基图稠密化）        [模型内]
                 ├─ soft     → 训练/评估
                 └─ tb_bits  → 部署（FAPI）
host：CRC 计算与判定 ＋ TB 打包 ＋ FAPI 封装
```

**码字装配**：主干的输出是**每 RE** 的 logits ✓，★ 消息传递在**码比特**上做 ✓，
★ 二者的对应由调制/rv/TBS/PRB 分配**唯一确定** ✓ ⇒ ★ **静态置换（gather，零参数）** ✓。

## 4. 与 Z 无关 ＋ 基图稠密化（两条关键设计）

**(a) 参数与 Z 无关**：★ 5G NR LDPC 是准循环码 ✓ ⇒ ★ 一层 ＝ 基图每条边上的一次运算 ✓、
★ 每条边 **Z 条车道并行** ✓ ⇒ ★ 权重在 Z 维共享 ✓。

**(b) 用稠密小矩阵，不用稀疏 gather/scatter**：★ 把 **Z 当 batch 维** ✓ ⇒
★ 一层 ＝ 对**基图（BG1: 46×68、316 条边）的稠密邻接**做运算 ✓
★ ⇒ ★ 每层 ≈ 68×22×Z（Z=320 时 ≈ 478 k MAC ✓）★ ⇒ ★ Core ML / ANE 友好 ✓。

## 5. 层内三步（消息函数只用标量/LUT）

| 步 | 运算 | 可学参数 |
|---|---|---|
| ① V→C | 软值减上轮 C→V，再乘**逐 RE 可靠性**（depth3 的 `post_eq_noise`）| 每（层, 变量度数）一个标量 |
| ② C→V | 排除自身的 min/次小（min-sum 形状），**分段线性 LUT（4–8 段）** | 每（层, 校验度数）一个 LUT |
| ③ 软值更新 | `soft += α·(C→V)`，且**先减旧值再换新值**（BP 的替换语义）| 每层一个阻尼标量 |

★ 全网络参数**几百个**（层数 × 度数 × 少量参数）✓。
★★ **不许**用 per-edge MLP 做消息函数 ✓（实测代价 6.5–76× 一次迭代 ✓）。

## 6. 深度与退出

| 项 | 决定 |
|---|---|
| 深度 | **固定 16 层** |
| 早退 | ★ **不做** ✓ —— ★ 任何早退都要**中途取回软值** ✓ ⇒ ★ 第二次设备穿越 ✓（见过程日志 D14/D16）|
| "提前放弃" | 不做（I6）|

★ 依据 ✓：★ 16 层全算在 CPU 上约 **94 µs** ✓，★ 而**一次设备调用的尾延迟就有 ~404 µs** ✓ ⇒ ★ 早退省的时间从来不是瓶颈 ✓。

## 7. 训练与数据

| 项 | 规定 |
|---|---|
| 数据 | 经典解码器的**参考库**：★ 每条记录含**解速率匹配后的输入（码字序）** ＋ 收敛软值 ＋ 迭代数 ＋ 成败 ✓ |
| 标签 | **传输的比特**（I1）；★ 只有在"经典解码器成功"的块上，其收敛码字才等价于传输比特 ✓ |

## 10. 术语（只留最容易被混淆的）

| 词 | 含义 |
|---|---|
| **Keras 层** | 可微、可组合、带权重的代码对象；★ **同一层被调用 16 次就是深度 16** ✓ |
| **一个"层"（消息传递）** | ★ 基图所有边上的一次运算 ✓，★ 与 Z 无关 ✓ |
| **早退** | 满足条件时不再走更深层；★ depth4 **不做** ✓ |
| **CB-CRC** | 经典解码器的**停止条件**；★ depth4 不早退，★ CRC 在 host 做 ✓ |
| **soft / tb_bits** | 同一模型的两个输出：★ 训练用前者 ✓、★ 部署用后者 ✓ |

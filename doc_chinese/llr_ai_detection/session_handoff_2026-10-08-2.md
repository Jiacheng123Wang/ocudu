### 3.2 具体的算法（★ 直接照做）

```python
# 对 cap002 的每个样本：
#   1. 读 <key>.txt 拿 alloc_prb / dmrs_symbols / bwp_size_rb / modulation
#   2. 读 <key>.bin  → y  (14, bwp_size_rb*12) complex64
#   3. 读 <key>_h.bin → H  (14, bwp_size_rb*12) complex64   ★ 链自己的 H
#   4. 读 <key>_ce.txt → noise_variance, snr
#   5. 掩码：ina = 分配内；isd = DM-RS 符号的导频 RE；m = ina & ~isd
#   6. X = y[m]/H[m]；s = mean|X| / mean|X_const|；Xn = X/s
#   7. X̂ = 最近星座点
#   8. ★★ 判据：残差 RMS / 噪声 RMS  ← 不是绝对阈值！
#         噪声 RMS（在 Xn 域）= sqrt(noise_variance)/mean(|H[m]|)/s
#   9. 报告：残差/噪声 的分布（中位、p10、p90），★ 按调制与 SNR 分层
```

### 3.3 判据（★ 预登记，且**已经在 `memo_08` 里**）

★ `memo_08` §4.4 的**残差噪声比**：
- ★ **≈ 1** ⇒ 经典判决已解释所有观测 ⇒ **可改善空间小**；
- ★ **≫ 1** ⇒ 有真实的可改善空间，**它的大小就是 `Δ_max` 的量级线索**。

★★ **注意**：★ 它**不是** `Δ_max`（那要 genie 臂）；★ 它给的是**量级线索与机制归因**。

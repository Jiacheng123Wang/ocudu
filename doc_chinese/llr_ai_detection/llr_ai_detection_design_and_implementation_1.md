## 19.601 ★★★★ 复查：★ `forward` 里**没有解码** ✓ —— ★ 但换 LDPC 它确实动了 **88 µs** ✗

**(a) ★★★ 用户的前提成立 ✓：★ `forward` 段不含 LDPC ✓**

|---|---|

| ★ **`forward`** ✓ | ★ **平面拼好 → 网络结果送出** ✓ |
| ★ `report` ✓ | ★ 送出 → 上报 ✓ |
| ★ `deliver` ✓ | ★ 上报 → 交付 ✓ |

★ ⇒ ★ **`forward` 只含 depth3 网络（CE＋EQ＋DEMOD）✓，★ LDPC 在它之后 ✓** ⇒

**(b) ★★★★ 但实测它确实变了 ✓ —— ★ 同会话交替，同捕获 ✓**

| ★ 轮 ✓ | ★ `--metal` ✓ | ★ `--metal-cpu-ldpc` ✓ |

| 1 ✓ | 299 ✓ | 211 ✓ |
| 2 ✓ | 295 ✓ | 202 ✓ |
| 3 ✓ | 299 ✓ | 217 ✓ |
| ★ 均值 ✓ | ★ **298** ✓ | ★ **210** ✓ |

★ ⇒ ★ **差 88 µs ✓，★ 三轮都复现 ✓，★ 不是漂移 ✓** ✓。

**(c) ★★★ 为什么 ✓：★ 不是"解码算在里面" ✗，★ 是**争用** ✓**

★ **不是解码更慢（那是另一件事 ✓），★ 而是解码**抢占**了下一帧的前向 ✓** ✓。

# ai_train

Training/export tooling for the HELENA AI channel estimator (datasets, training, Core ML
conversion, evaluation).

The operator's documentation for this directory is in Chinese and lives with the rest of the
design records: `doc_chinese/ai_ce/ai_train/README.md`, next to the G-5 online-adaptation manual
(`doc_chinese/ai_ce/ai_train/AI_CE_G5_manual.md`) and the training memos in `doc_chinese/ai_ce/`.
